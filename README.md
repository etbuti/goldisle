# Goldisle Music — Static Site

This is a lightweight static music platform for Goldisle Music, designed to be used with DeepCurrent Browser.

## Deploy
1. Put the directory on your web host: `/music/` (e.g. https://goldisle.org/music/)
2. Upload `media/` files (MP3 + cover images).
3. Edit `songs.json` to reflect real files and metadata.
4. (Optional) enable `sw.js` on HTTPS host to enable caching.

## GitHub Pages
- Create `gh-pages` branch or use repository `Settings -> Pages` to serve from `/docs` or `main` branch.
- Ensure `songs.json` and media files are committed to the branch.
